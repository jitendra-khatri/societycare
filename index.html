How SocietyCare works

Residents add issues. Search and filters make recurring problems easy to identify, while the summary shows the overall volume.

When shared hosting is enabled, residents see new reports automatically. Use Export CSV to refine issues in a committee spreadsheet; committee status changes can be enabled after administrator login is set up.
